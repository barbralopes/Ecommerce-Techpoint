# 🛒 Techpoint - E-commerce

Projeto desenvolvido em grupo no 4º período do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

O **Techpoint** é uma aplicação de e-commerce desenvolvida com foco em organização de código, trabalho em equipe e aplicação de conceitos aprendidos em sala de aula.

---

## 📌 Sobre o Projeto

O sistema simula uma plataforma de loja virtual, permitindo o gerenciamento de produtos e categorias, além de funcionalidades relacionadas ao fluxo básico de uma aplicação de comércio eletrônico.

O projeto foi desenvolvido com o objetivo de:

- Aplicar boas práticas de desenvolvimento
- Trabalhar com controle de versão (Git/GitHub)
- Praticar organização de projeto
- Simular um ambiente real de desenvolvimento em equipe
- Consolidar conhecimentos do curso

---

## 🚀 Funcionalidades

- Cadastro de produtos
- Listagem de produtos
- Cadastro de categorias
- Edição de registros
- Exclusão de registros
- Estrutura organizada por camadas
